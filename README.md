# 3D FAST-NUCES Islamabad

Long-term 3D reconstruction of the FAST-NUCES Islamabad campus.

## Goal
Create a visually strong and proportionally accurate digital campus that supports both:
- high-quality Blender rendering/animation;
- optimized real-time use in a game engine, web experience, or similar interactive environment.

## Locked foundation
- Blender master scene is authoritative.
- Accuracy before detail.
- Reconstruct the complete campus as a validated low-detail blockout first.
- Refine buildings one at a time after blockout approval.
- Use supplied campus photographs, maps, measurements, and free reconstruction/photogrammetry tools as evidence.
- Maintain reusable assets and derive optimized versions from the authoritative master rather than maintaining a second independently modeled campus.
- Document major decisions and evidence so future agents can re-ground from the repository.

## Current status
Production reconstruction is currently **frozen**.

The active direction is a separate building-quality test using supplied photographs. Its purpose is to determine the strongest practical Blender workflow before applying that workflow to FAST campus production.

Read `AGENTS.md` and `docs/STATUS.md` before doing any work.
