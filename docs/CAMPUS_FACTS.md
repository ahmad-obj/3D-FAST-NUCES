# Campus Facts

Authoritative project facts and corrections that override stale public map labels.

## Block naming and current layout

- **A Block** = Management block.
- **B Block** = Engineering block.
- **C Block** = original Computing block.
- **D Block** = newer Computing block.
- Older OpenStreetMap data is stale relative to the current campus layout.
- In the older map state, the area now occupied by **D Block** contained the mosque.
- The mosque has since been relocated, and **D Block** now occupies that former mosque area.

## Source priority for this correction

This layout correction comes from direct current-campus user knowledge and therefore overrides stale OSM labeling for the present-day reconstruction.
