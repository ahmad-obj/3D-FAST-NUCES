# Campus Facts

Authoritative project facts and corrections that override stale public map labels.

## Block naming and current layout

- **A Block** = Management block.
- **B Block** = Engineering block.
- **C Block** = original Computing block.
- **D Block** = newer Computing block.
- Older OpenStreetMap data is stale relative to the current campus layout.
- In the older map state, the area now occupied by **D Block** contained the mosque.
- The mosque has since been relocated, and **D Block** now occupies that former mosque area.

## Source priority for this correction

This layout correction comes from direct current-campus user knowledge and therefore overrides stale OSM labeling for the present-day reconstruction.

## OpenStreetMap usage policy

OpenStreetMap may still contain useful and reasonably accurate geometry for older unchanged parts of the campus, including building footprints, relative spacing, roads, lawns, and dimensions. Treat it as **dimensionally useful but temporally incomplete**.

For every OSM-derived feature:
- keep and use its geometry when it still matches the current campus;
- verify changed or uncertain areas against newer imagery, photographs, measurements, or direct campus knowledge;
- never assume an OSM feature is current merely because its geometry is precise.

## Modeling implication

Do not reproduce the old OSM arrangement as the present-day campus. Use OSM as a geometric baseline where still valid, then patch changed areas such as D Block and the relocated mosque from newer evidence.
