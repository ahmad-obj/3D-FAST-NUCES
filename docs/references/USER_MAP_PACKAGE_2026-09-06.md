## Contents inspected

## Accuracy policy
- Satellite imagery: strong for current roof layout, relative placement, roads/open areas; weak for exact heights and hidden geometry.
- OSM geometry: useful for dimensions/footprints where the mapped structure still exists, but temporally incomplete for recent campus changes.
- Elevation samples: broad terrain context only; not survey-grade and not building-height data.
- User-prepared notes: useful guidance, but verify important dimensions before promoting them to authoritative campus facts.
